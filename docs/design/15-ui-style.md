# qteasy-ai 工作台界面风格（0.2.0 已实现）

本文只记录工作台**现在长什么样、怎么操作**，方便以后改界面时对齐。原则仍在 qteasy 仓 `knowledge/domain/qteasy-ai-ui-guidance.md`。色值以 `qteasy_ai/workbench/static/app.css` 的 `:root` 为准；改颜色先改那里，再改本文。

## 1. 字体与密度

- 界面字号 13px，行高 1.45。字体是系统无衬线：`-apple-system`、`Segoe UI`、`system-ui`。
- 代码、计划正文里的等宽块用 `ui-monospace` / `Menlo` / `Consolas`。
- 圆角：卡片与面板 6px，按钮 4px。
- 主按钮用强调色底、白字。危险操作只用错误色文字，不另做一块大红底。

## 2. 颜色

默认是暗色。浅色由 `html[data-theme="light"]` 覆盖同一组变量。

| 用途 | 暗色 | 浅色 |
|------|------|------|
| 页面底 | `#1e1e1e` | `#f5f5f5` |
| 侧栏底 | `#181818` | `#ffffff` |
| 正文 | `#cccccc` | `#242424` |
| 次要文字 | `#8b8b8b` | `#5c5c5c` |
| 强调 | `#3794ff` | `#0b6bcb` |
| 成功 | `#89d185` | `#1b7f3a` |
| 警告 | `#cca700` | `#8a6a00` |
| 错误 | `#f48771` | `#c23b22` |
| 用户气泡 | `#0e4d7b` | `#c5e4fb` |
| 组标题底 | `#242424` | `#ececec` |
| 代码底 | `#151515` | `#f3f3f3` |

组标题（时间桶、Workspace 的 NOW / AUDIT / THIS SESSION、Settings 的 SERVER / APPEARANCE / PROVIDERS）共用一套可折叠标题：底比所在栏略深，组名大写。

## 3. 模式徽章

Composer 上的模式是一枚小徽章，不是顶栏里的第二套开关。

- **Ask**：绿。暗色字 `#3ddc6e`，浅底绿。
- **Plan**：黄。暗色字 `#e6c34a`。
- **Agent**：深灰底、浅字；浅色主题下是浅灰底、深字。

槽位填满不会把徽章改成 Agent。

## 4. 三栏

从左到右：会话列表与对话、产物、工作区。折叠会话列表只改变对话栏宽度；折叠工作区只改变产物栏宽度，窄条贴在屏幕右缘。会话与产物之间可以拖开，两侧有最小宽度。

对话区只显示内核写好的卡片（提问回答、计划短通知、澄清选项、结果、错误、模式提示）。计划全文在中间栏的 `plan` 产物里打开，不铺进对话。

Enter 换行。Ctrl 或 ⌘ 加 Enter 发送。确认计划是可选快捷，不锁住输入框。

Composer 底部右侧：回形针与圆形向上箭头发送按钮（约与 Mode / Provider 徽章同高）。发送钮颜色跟模式：Ask 绿、Plan 黄、Agent 白（浅色主题用同色系深底）。已挂附件时，在输入框上方显示文件芯片（类型图标、文件名、× 移除）。拖文件到 Composer 区域时边框虚线高亮。

## 5. 交互卡（澄清 / Plan ready）

Session 栏里两张活交互卡共用 `ix-card` 壳：固定高度 300px、横贯内容区宽度、不可拖拽缩放。结构为标题栏 / 可滚动中部 / 底栏。

- **标题栏**：左标题；澄清卡右侧有 `< X of N >` 翻页。Plan ready 右侧留空。
- **底栏**：靠右。最右是实心强调色主按钮（Submit / Confirm / Apply）。其余是无边框纯文字短标签（End、Back、View、Change、Cancel），悬停 `title` 显示全称。Cancel 不用错误色。
- **澄清卡中部**：问题正文；其下为 hint / 拒因；选项按行冠 A/B/C，字母在小方框里，选中只填满该方框。末行永远是开放输入（下一字母 +「请输入 / Please input...」），无边框，行高与其它选项一致。字母不进提交值。
- **Plan ready 中部**：Job / plan id / hint；改参数时为带边框的槽位表单。

Ask / Result 无边气泡、过程折叠、产物栏不套此壳。

## 6. 不做

不做移动端折叠。不绑定 AG Grid 或 Monaco。视觉可以再改，编排仍是薄 HTTP 和同一套数据。
