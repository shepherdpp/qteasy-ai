# qteasy-ai 0.2.0 实现总览

本文记录即将对外发布的实现，供以后设计和发版对照。PyPI 上的 **0.1.0** 只是 Stage A 骨架。本次包号是 **0.2.0**。阶段 A 的备忘仍在 [11](11-ai-shell-stage-a.md)、[12](12-ai-shell-a0-adrs.md)、[13](13-ai-shell-a0-implementation-order.md)，不在这里重写。

契约细节在 qteasy 仓的产品顶层与 Domain。本文不抄 Job 全表。注册名见 [OFFICIAL_SKILL_CATALOG.md](../OFFICIAL_SKILL_CATALOG.md)。

## 1. 一句话

现行 α：意图门出 Job，已知对象走菜谱，没有菜谱时在合法边上出短 DAG，用户确认后再执行。CLI、Notebook、Workbench 共用同一个助手，执行记录都进 `.qteasy/ai/runs/`。

## 2. 已交付

- **Ask**：只回答问题，不调用技能、不写 `runs/`。没有模型时用包内官方知识库；有模型时答案跟随问句语言。
- **Plan**：只生成计划。对话里是一句短通知；完整说明在 `plan` Artifact（`plan.md`）。改这份 Markdown 不会改变执行。JSON 才是执行依据。
- **Agent / run**：确认之后才执行。槽位填满不会自动执行。实盘只出计划，不会自动下单。
- **官方能力**：13 个官方 Job、22 个已注册技能、18 条官方知识库。用户知识库只预置目录骨架，Ask 不检索它。
- **多轮会话**：同一 `session_id` 上续说可以修订上一份计划。澄清用选项；跳过则本句失败结束。
- **工作台**：桌面三栏（会话、产物、工作区）。产物可看可关。长任务有心跳、已用时间、步进度；Stop 在下一步边界停下并丢弃本次结果，Background 让任务在后台继续。设置里可以管理 Provider 池；无模型的 Mode-R 内置且不可删除。
- **最小 TUI**：同一套人读卡，没有产物栏。
