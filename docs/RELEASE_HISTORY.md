# 发布历史

本页记录 qteasy-ai 各版本里**用户能看到的**变化。最新版本在最上方。英文短条见仓库根目录的 [CHANGELOG.md](../CHANGELOG.md)，详细事实以本页为准。

升版时如何写这一页，见 qteasy 仓 `.cursor/rules/10-working-versioning-semver.mdc` 的 qteasy-ai 节。

## 0.3.1 (2026-10-31)

相对 0.3.0，工作台澄清与计划确认卡更好用，澄清填槽路径更清晰。

- **澄清变成分步向导。** 缺多项时一次只问一格，标题栏显示进度；各步选项各自列出（每步最多五个），攒齐后再一次性提交。主动结束本请求时，卡内先确认再收口。
- **澄清卡与计划确认卡样式统一。** 固定高度、字母选项行、底栏短标签；悬停可看到完整按钮说明。
- **澄清进行中，输入框再发字会换题。** 工作台里不能再靠打字填槽或打「跳过」收口；请用卡内选项、开放输入或「结束本请求」。命令行仍可打字补槽。
- **连续答错有最后机会。** 第三次仍不对会提示最后一次机会；第四次仍不对则整单失败，文案与主动结束本请求不同。

## 0.3.0 (2026-10-28)

相对 0.2.3，问答能覆盖更多手册主题，工作台日常操作更顺手。

- **问答覆盖面明显加宽。** 数据怎么查、本地库与通道、HistoryPanel 是什么以及怎么看图、策略与信号（含基类、合成、实现与追溯）、回测与优化在做什么、如何看结果、防未来函数在守什么、实盘边界、以及工作台里 Ask / Plan / 确认分别从哪里进，都能落到对应说明，而不再轻易停在「库里没有」。
- **问答语气与空答更干净。** 可以说「用人话讲」并在同一会话里接着用；问到未来函数或 PT / PS / VS 时，会落在相关主题里。库里没有对应说明时，聊天区只留一条跟你问句语言一致的助手说明，不再多出一张错误卡。
- **工作台更好用。** 可以在会话里附上文件再提问；助手输出支持一键复制，复制成功有勾选与状态栏提示。删除会话时会一并清掉它名下的运行记录。侧栏会话列表会缩短过长的上一句预览；尚未落盘的会话也可以先改名。

## 0.2.3 (2026-10-15)

- **入门与总览更好答。** 「qteasy 是什么」、模块如何串起来、相对自己写回测有什么优势，以及安装环境、数据源 FAQ、如何求助、能力地图，都能落到对应说明。
- **同一会话里可以接着问。** 系统会记住上一轮问答焦点；点名某个主题或更早一轮时，会按那一轮继续答，而不再靠整句菜单序号。相关说明会邀请你再问，而不是整段塞进当前答案。
- **工作台代码更易扫。** Ask 与 Result 里的代码块会标出语言；只有 Python 会高亮，bash 与纯文本保持原样。
- **助手默认叫 Kairos。** 被问「你是谁」时会这样自我介绍；界面标题仍是 qteasy-ai。

## 0.2.2 (2026-10-08)

- **没有配置模型时，原句对得上就只答那一条。** 中英文交界多写或少写一个空格，看到的是同一条说明。例如「如何用qteasy回测」和「如何用 qteasy 回测」都是回测入门，不再变成「qteasy 是什么」。
- **配置了模型时，换一种说法也会停在同一主题。** 「如何用qteasy进行回测」会讲回测，不再被产品介绍带走。模型定不准主题，或选不中卡片时，问答会停下来并建议改用 Plan，不再硬凑一段介绍。

## 0.2.1 (2026-10-07)

- **问答更贴题。** 问报错或实盘边界时，答案只讲这一类，不再夹一段入门说明。例如问会不会自动实盘，只回答安全边界。
- **泛泛提到「策略」，不再被内置策略清单抢走。** 写双均线、问参数优化，会落到对应主题。点名某条策略（如 macd 的默认参数），或明确说「列出内置策略」，仍会给出实时说明。只问「策略是什么」而没有对应主题时，问答会停下来，并建议改用 Plan。
- **版本信息。** 可用 `qteasy_ai.version_info` 读取 major / minor / patch 等字段，用法与 `qteasy.version_info` 相同。

## 0.2.0 (2026-10-05)

相对 0.1.0，这是第一次带Web工作台的版本。

- **问答、计划与执行分开**。`qteasy-ai ask` 只回答问题，不会调用技能，也不会再给出一份空的试跑计划。`plan` 先给你看步骤；确认之后才会取数、回测或优化。没有配置模型也可以用。
- **工作台APP**。`qteasy-ai serve` 打开一个Web工作台：对话、产物、当前任务。计划说明在产物里打开。可以停止一次运行，或让它在后台继续。导出 K 线时，服务不会再被绘图窗口带崩。
- **官方能力**。可以用自然语言完成环境检查、有界补数、读数与摘要、内置策略回测与优化、看懂上一次回测，以及按双均线模板起草策略。实盘只会生成计划，不会自动下单。
- **接着说**。同一会话里可以补上日期或标的，也可以改上一份计划。澄清时可以直接选，跳过则这一句结束。进程中断后重新打开会话，可以再次确认同一份计划，不会从停下的那一步接着跑。
- **模型**。可以在设置里保存多个 Provider 并切换。列表不会显示密钥。不配置模型时，问答走内置说明，计划按规则生成。模型请求默认等到 120 秒，可用环境变量 `QTEASY_AI_TIMEOUT` 修改。

## 0.1.0 (2026-08-06)

从 qteasy 拆出的第一个公开版本，只有命令行和 Notebook。

- 可以用 `ask`、`plan`、`run` 走「先看计划、再执行」的最短路径，并检查模型是否配好。
- 能查看内置策略说明、K 线摘要，以及把 K 线导出成图。
- 本机会记下配置、环境事实和运行记录。

工作台、官方技能目录和多轮会话不在这个版本里，见上方 0.2.0。
