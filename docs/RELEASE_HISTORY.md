# 发布历史

本页记录 qteasy-ai 各版本里**用户能看到的**变化。最新版本在最上方。英文短条见仓库根目录的 [CHANGELOG.md](../CHANGELOG.md)，详细事实以本页为准。

升版时如何写这一页，见 qteasy 仓 `.cursor/rules/10-working-versioning-semver.mdc` 的 qteasy-ai 节。

## 0.2.1 (2026-10-07)

- **问答更贴题。** 问报错或实盘边界时，答案只讲这一类，不再夹一段入门说明。例如问会不会自动实盘，只回答安全边界。
- **泛泛提到「策略」，不再被内置策略清单抢走。** 写双均线、问参数优化，会落到对应主题。点名某条策略（如 macd 的默认参数），或明确说「列出内置策略」，仍会给出实时说明。只问「策略是什么」而没有对应主题时，问答会停下来，并建议改用 Plan。
- **版本信息。** 可用 `qteasy_ai.version_info` 读取 major / minor / patch 等字段，用法与 `qteasy.version_info` 相同。

## 0.2.0 (2026-10-05)

相对 0.1.0，这是第一次带Web工作台的版本。

- **问答、计划与执行分开**。`qteasy-ai ask` 只回答问题，不会调用技能，也不会再给出一份空的试跑计划。`plan` 先给你看步骤；确认之后才会取数、回测或优化。没有配置模型也可以用。
- **工作台APP**。`qteasy-ai serve` 打开一个Web工作台：对话、产物、当前任务。计划说明在产物里打开。可以停止一次运行，或让它在后台继续。导出 K 线时，服务不会再被绘图窗口带崩。
- **官方能力**。可以用自然语言完成环境检查、有界补数、读数与摘要、内置策略回测与优化、看懂上一次回测，以及按双均线模板起草策略。实盘只会生成计划，不会自动下单。
- **接着说**。同一会话里可以补上日期或标的，也可以改上一份计划。澄清时可以直接选，跳过则这一句结束。进程中断后重新打开会话，可以再次确认同一份计划，不会从停下的那一步接着跑。
- **模型**。可以在设置里保存多个 Provider 并切换。列表不会显示密钥。不配置模型时，问答走内置说明，计划按规则生成。模型请求默认等到 120 秒，可用环境变量 `QTEASY_AI_TIMEOUT` 修改。

## 0.1.0 (2026-08-06)

从 qteasy 拆出的第一个公开版本，只有命令行和 Notebook。

- 可以用 `ask`、`plan`、`run` 走「先看计划、再执行」的最短路径，并检查模型是否配好。
- 能查看内置策略说明、K 线摘要，以及把 K 线导出成图。
- 本机会记下配置、环境事实和运行记录。

工作台、官方技能目录和多轮会话不在这个版本里，见上方 0.2.0。
